# SHAKERTAINMENT website starter

A responsive Next.js website starter using the requested red and green brand palette.

## Requirements
- Node.js 18.17 or later
- npm

## Run locally
1. Extract this ZIP.
2. Open the `shakertainment-website` folder in VS Code.
3. Open Terminal in VS Code.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Visit http://localhost:3000

## Before publishing
- Replace the placeholder email `hello@shakertainment.co.za` in `app/page.tsx`.
- Add your own music, video, photography and fashion images.
- Add real social media links and booking details.
- Review the YFM description and add the official YFM contact/donation details if applicable.

## Publish
This project can be deployed to Vercel. Import the project into a GitHub repository, then import that repository at https://vercel.com/new. Vercel will provide a public temporary URL ending in `vercel.app`; you can connect a custom domain later.
